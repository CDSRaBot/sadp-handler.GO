## Итоговый статус

M4 существенно реализован, но Issue #36 пока не готова к закрытию.

Реализованы общие command/result contracts, CLI-парсинг, CLI runtime,
Bubble Tea TUI, discovery session integration, interface selection, filtering
и TUI target confirmation.

## Реализованные компоненты

### CLI и общие команды

- Безопасная токенизация CLI с quoting и документированными escape-последовательностями.
- `ParseCLICommand`.
- `ParseConsoleCommand`.
- Проверка shell syntax, malformed quotes и invalid arguments.
- `SelectUIMode`.
- `SearchDevices`.
- `DispatchCommand`.
- Typed failure codes:
  - `invalid_argument`;
  - `unsupported`;
  - `operation_failed`;
  - `canceled`.

Основные файлы:

- `internal/ui/parse.go`
- `internal/ui/ui.go`

### CLI runtime

- Глобальные параметры:
  - `--ui`;
  - `--once`;
  - `--lang`;
  - `--format`.
- CLI REPL.
- One-shot execution.
- JSON/text output.
- Разделение stdout/stderr.
- Exit codes:
  - `0` — success;
  - `1` — operational/command failure;
  - `2` — invalid invocation;
  - `130` — interrupted one-shot.
- Terminal capability validation.

Основной файл:

- `internal/ui/runtime.go`

### TUI

Подключены:

- Bubble Tea;
- Bubbles;
- Lip Gloss.

Реализованы:

- зоны Devices, Details и Console;
- keyboard focus navigation;
- command history;
- безопасная history policy без `--password`;
- device selection;
- incremental filter;
- safe detail rendering;
- TUI context cancellation;
- startup interface selection;
- TUI target resolution;
- bulk confirmation через `y/n`.

Основные файлы:

- `internal/ui/tui.go`
- `internal/ui/tui_state.go`
- `internal/ui/tui_mutation.go`
- `internal/ui/interface_selection.go`

### M6 discovery integration

- Реализован `M6DiscoverySessionService`.
- Используются `adapter.ListInterfaces` и `discovery.DiscoverOnInterface`.
- Interface selection ограничена eligible interfaces.
- Discovery events передаются в TUI через Bubble Tea messages.
- Повторные события агрегируются по `(MAC, sender)`.
- Некорректные события не попадают в UI snapshot.

Основной файл:

- `internal/ui/m6_session.go`

### M8 application composition

- Добавлен `app.Compose`, преобразующий validated M7 settings в typed runtime config.
- Добавлены duration, multicast, logging level и localization filesystem mappings.
- Добавлена защита localization path от выхода за `baseDir`.
- Добавлены `ServiceSet`, `ApplicationDependencies` и `BuildDependencies`.
- Добавлен executable entry point `cmd/sadp-handler`.
- CLI overrides применяются поверх настроек через `RunCLIWithDefaults`.
- Добавлен stateful M5 localization adapter с загрузкой, переключением и
  экспортом locale catalogs.
- Исправлен FS boundary: M5 получает application root и использует
  `locales/<code>.json` согласно своему контракту.
- Исправлено разрешение настроенного `localization.directory`: M5 теперь
  получает virtual FS, отображающий `locales/` на фактический каталог из M7.
- Добавлены typed `ActivationService` и `NetworkService` seams в M4,
  validation mutation targets, confirmation enforcement и mapping
  `DeviceOperationError` в command failures с per-device outcomes.
- Mutation dispatch сохраняет частичные per-device outcomes при operational
  failure bulk-операции и отклоняет пустой успешный ответ service.

Основные файлы:

- `internal/app/composition.go`
- `cmd/sadp-handler/main.go`
- `internal/ui/runtime.go`

## Оставшиеся блокеры Issue #36

1. Production startup wiring между M8, M4, M0 и M6 для protocol services.
2. Реальные activation/network workflows и challenge/response parsing.
3. Подключение production mutation services к новым M4 seams.
4. Полный acceptance review по Issue #36.
5. Финальный verification gate после завершения M4/M7/M8.

`activate` и `network` намеренно остаются на implementation gate и возвращают
`unsupported` до появления end-to-end workflows. До этого момента UI не читает
пароли и не открывает сетевые операции для этих команд.
