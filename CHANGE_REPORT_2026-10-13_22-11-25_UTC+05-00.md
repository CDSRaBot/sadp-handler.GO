### Оценка вызова из ИИ-агента

По проектируемому контракту агент может вызывать приложение как локальный процесс через one-shot CLI и обрабатывать JSON-ответ. Предусмотренная форма выглядит так:

```text
sadp-handler --ui=no --format json --once discover --interface 4 --timeout 5s
```

Контракт предусматривает один JSON-результат в stdout, отдельный stderr для подсказок/диагностики и стабильные коды завершения: `0` — успех, `1` — ошибка команды или операции, `2` — неверный запуск, `130` — прерывание one-shot. Это описание планируемого поведения, а не проверенный запуск.

## Ограничения и статус

- Согласно [`README.md`](README.md), репозиторий пока содержит документацию, Go-реализация не начата. Поэтому исполняемого CLI и фактически работающего интерфейса для агента ещё нет.
- `discover` потребует доступного сетевого интерфейса и multicast-доступа; указанное значение `--interface` должно соответствовать целевой системе.
- `activate` и `network` пока должны завершаться отказом `unsupported` без чтения секретов и без сетевого ввода-вывода.
- В спецификациях описан вызов процесса через CLI; отдельный API/MCP-контракт для интеграции с агентскими платформами не определён.
- Для безопасной будущей интеграции следует передавать параметры через argv, разбирать stdout как JSON отдельно от stderr и не включать секреты в аргументы команды.
