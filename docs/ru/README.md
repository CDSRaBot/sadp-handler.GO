# SADP-handler (v0.1.0)

**SADP-handler** — профессиональная высокопроизводительная утилита на Go для обнаружения, активации и настройки сети устройств Hikvision с помощью протокола L2 **Search Active Device Protocol (SADP)**.

## Текущий статус проекта: фаза проектирования завершена

Репозиторий содержит документацию проекта; реализация Go пока не начата. Локальная реализация на Python (`../examples/SADP-app`) описана как поведенческий референс, но совместимость протокола SADP ещё не подтверждена. Универсальные заготовки HTTP/JSON удалены, поскольку они не соответствовали спецификации SADP. Нерешённые вопросы перечислены в системной спецификации; иерархические спецификации модулей и атомарных процедур находятся в каталоге `spec/`.

### Основные возможности

- **Ядро на Go**: использует модель параллелизма Go — горутины, каналы и `context.Context`.
- **Обнаружение на L2**: поиск камер и NVR в локальном сегменте сети, в том числе без настроенного IP-адреса.
- **Пакетная активация**: активация нескольких неактивированных устройств с проверкой сложности пароля.
- **Безопасность**: безопасный разбор XML с помощью стандартной библиотеки Go (`encoding/xml`) и строгая проверка сетевых данных.
- **CLI прежде всего**: утилита рассчитана на удобный запуск из командной строки, с поддержкой структурированной конфигурации и журналирования.
- **Документация как код**: иерархическая спецификация системы описывает процедуры вплоть до атомарного уровня.

## Технологический стек

- **Путь Go-модуля**: `github.com/CDSRaBot/sadp-handler.GO`
- **Язык**: Go 1.22+ (кроссплатформенная поддержка)
- **Параллелизм**: goroutines, channels, `sync`, `context`
- **Сетевое взаимодействие**: `net`, `net/http`, `net/udp`, `net/tcp`
- **Обработка XML**: `encoding/xml` со строгим разбором и проверкой
- **CLI**: стандартная библиотека `flag` или `cobra` (если будет выбрана при реализации)
- **Конфигурация**: JSON/YAML/TOML через `viper` или стандартную библиотеку
- **Журналирование**: `log/slog` или библиотека структурированного журналирования
- **Тестирование**: `testing`, `go test`, `go vet`
