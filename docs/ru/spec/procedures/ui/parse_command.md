# Спецификация процедуры: P4.3 — ParseConsoleCommand
## Модуль: M4 — Интерфейс командной строки

Разобрать одну введённую в командной панели TUI строку в типизированную команду приложения. Грамматика, допустимые аргументы, ошибки и safety boundaries определены в [нормативной процедуре на английском](../../../spec/procedures/ui/parse_command.md).

Поддерживаются только команды приложения. Строка никогда не передаётся системной оболочке; секреты не должны сохраняться в истории или диагностике.
