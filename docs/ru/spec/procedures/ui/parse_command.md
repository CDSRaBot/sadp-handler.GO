# Спецификация процедуры: P4.3 — ParseConsoleCommand
## Модуль: M4 — Интерфейс командной строки

Разобрать одну команду из панели TUI и преобразовать её в общий типизированный каталог P4.5. Полные грамматика, правила выбора целей, ошибки и тесты приведены в [нормативной процедуре на английском](../../../spec/procedures/ui/parse_command.md).

Доступны `discover`, `activate`, `network`, `language`, `help`, `version`, `quit` и `--export-locale-template PATH`. Обе командные грамматики направляют проверенную команду в общий dispatcher; парсер не запускает shell, не выполняет ввод-вывод и не собирает секреты. При отсутствии явного MAC операция использует текущий набор выделенных устройств или сфокусированное устройство, если выделения нет.
