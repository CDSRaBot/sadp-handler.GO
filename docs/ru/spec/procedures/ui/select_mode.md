# Спецификация процедуры: P4.1 — SelectUIMode
## Модуль: M4 — Интерфейс командной строки

## 1. Назначение

Определить режим взаимодействия процесса по глобальному параметру `--ui` и доступности терминала до запуска рабочих процессов приложения.

## 2. Контракт Go

```go
type InterfaceMode string

const (
    ModeTUI InterfaceMode = "tui"
    ModeCLI InterfaceMode = "cli"
)

func SelectUIMode(value string, stdinIsTerminal, stdoutIsTerminal bool) (InterfaceMode, error)
```

- Парсер аргументов передаёт значение `"yes"`, если `--ui` не указан. Параметр принимает только `"yes"` или `"no"`; остальные значения, включая пустое, недопустимы.
- Значение `"yes"` выбирает `ModeTUI`, только если и ввод, и вывод являются доступными терминалами. В противном случае возвращается понятная ошибка с рекомендацией `--ui=no`.
- Значение `"no"` выбирает `ModeCLI` независимо от доступности терминала; перенаправленные потоки допустимы в этом режиме.
- При неверном значении или недоступности требуемого терминала возвращать ошибку и не возвращать пригодный режим. Не переключаться между режимами незаметно.

## 3. Требования к обработке

1. Разбирать и проверять `--ui` до начала обнаружения, открытия сокетов и вызова любых других рабочих процессов приложения.
2. Не определять запрошенный режим по результату проверки терминала. Доступность терминала используется только для проверки явно выбранного или заданного по умолчанию режима.
3. Не менять выбранный режим в течение жизни процесса. Команда TUI может запускать рабочие процессы приложения и отображать результаты, но для перехода в стандартный CLI требуется отдельный запуск процесса.
4. Проверка терминала находится за пределами этой чистой процедуры; вызывающий код передаёт признаки доступности фактических потоков ввода и вывода.

## 4. Ошибки и тесты

Возвращать различимые ошибки для недопустимого параметра и отсутствующего доступного терминала, не включая чувствительные значения. Проверять значение по умолчанию на границе парсера аргументов, точные допустимые значения, пустые/неверные значения, проверку обоих потоков, перенаправленные потоки CLI и отсутствие запуска рабочих процессов при ошибке выбора режима.
