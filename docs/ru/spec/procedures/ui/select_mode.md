# Спецификация процедуры: P4.1 — SelectUIMode
## Модуль: M4 — Интерфейс командной строки

## 1. Назначение

Определить режим взаимодействия процесса по глобальному параметру `--ui` и доступности терминала до запуска рабочих процессов приложения.

## 2. Контракт Go

```go
type InterfaceMode string

const (
    ModeTUI            InterfaceMode = "tui"
    ModeCLIInteractive InterfaceMode = "cli-interactive"
    ModeCLIOnce        InterfaceMode = "cli-once"
)

func SelectUIMode(value string, once bool, stdinIsTerminal, stdoutIsTerminal bool) (InterfaceMode, error)
```

- Парсер аргументов передаёт значение `"yes"`, если `--ui` не указан. Параметр принимает только `"yes"` или `"no"`; остальные значения, включая пустое, недопустимы.
- `"yes"` при `once == false` выбирает `ModeTUI`, только если ввод и вывод являются доступными терминалами; `"yes"` с `--once` недопустим.
- `"no"` без `--once` выбирает интерактивный CLI REPL и требует терминальный stdin; stdout разрешено перенаправить. Если stdin не терминал, сообщить об ошибке с рекомендацией выполнить one-shot с `--once`.
- `"no"` с `--once` выбирает однокомандный CLI, допускающий перенаправленные потоки.
- При неверном значении или недоступности требуемого терминала возвращать ошибку и не возвращать пригодный режим. Не переключаться между режимами незаметно.

## 3. Требования к обработке

1. Разбирать и проверять `--ui`/`--once` до начала обнаружения, открытия сокетов и вызова любых других рабочих процессов приложения.
2. Не определять запрошенный режим по результату проверки терминала. Доступность терминала используется только для проверки явно выбранного или заданного по умолчанию режима.
3. Не менять выбранный режим в течение жизни процесса. Для перехода между TUI, REPL и one-shot CLI требуется отдельный запуск процесса.
4. Проверка терминала находится за пределами этой чистой процедуры; вызывающий код передаёт признаки доступности фактических потоков ввода и вывода.

## 4. Ошибки и тесты

Возвращать различимые ошибки для неверного сочетания параметров и отсутствующего нужного терминала. Проверять значения по умолчанию, TUI terminal input/output, REPL terminal stdin, redirected CLI stdout, one-shot redirected streams и запрет `--once` с TUI.
