# Спецификация процедуры: P4.5 — DispatchCommand
## Модуль: M4 — Интерфейс командной строки

Определить единый типизированный каталог команд, результаты и границу диспетчеризации для TUI, CLI REPL и one-shot CLI. Нормативные Go-типы, JSON-контракт, правила выбора целей и ошибок приведены в [англоязычной спецификации P4.5](../../../spec/procedures/ui/dispatch_command.md).

- Раздельные парсеры TUI/CLI формируют общие варианты команды; dispatcher направляет их в рабочие процессы и M5, не выполняя протокольную или сетевую логику в M4.
- Discovery поддерживает непрерывную политику TUI с немедленным первым probe и интервалом 60 секунд, либо конечную CLI-политику `--timeout`/`--repeat`.
- Видимый список устройств объединяет повторные объявления по паре нормализованных MAC и адресу отправителя; это ключ отображения, не протокольная корреляция.
- Результаты активации/настройки сети содержат статус по каждому устройству. До проверки протокола эти команды завершаются явным отказом без чтения секрета и без сетевого ввода-вывода.
