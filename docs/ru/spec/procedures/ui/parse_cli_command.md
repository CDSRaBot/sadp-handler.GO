# Спецификация процедуры: P4.4 — ParseCLICommand
## Модуль: M4 — Интерфейс командной строки

Разобрать аргументы неинтерактивного CLI в типизированный запрос приложения. Полная грамматика команд, опций и проверок определена в [нормативной процедуре на английском](../../../spec/procedures/ui/parse_cli_command.md).

Проверять взаимоисключающие параметры до сетевой активности. Секреты следует получать безопасным способом, не включать в историю и не выводить в диагностике.
