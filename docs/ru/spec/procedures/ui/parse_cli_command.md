# Спецификация процедуры: P4.4 — ParseCLICommand
## Модуль: M4 — Интерфейс командной строки

## 1. Назначение

Преобразовать одну команду CLI — введённую в REPL или переданную аргументами при однократном запуске — в типизированную команду общего каталога. Парсер проверяет только синтаксис; он не исполняет команды и не выполняет ввод-вывод.

## 2. Контракт Go

```go
func ParseCLICommand(args []string) (Command, error)
func TokenizeCLIInput(line string) ([]string, error)
```

- `ParseCLICommand` получает токены одной команды после того, как точка входа обработала исполняемый файл и процессные параметры (`--ui`, `--lang`, `--format`, `--once`).
- Ввод REPL токенизируется функцией `TokenizeCLIInput`; аргументы one-shot уже разделены операционной системой и напрямую передаются в `ParseCLICommand`.
- Для эквивалентных аргументов оба пути создают один вариант команды и применяют одинаковые проверки.
- Отклонять пустой ввод, неизвестные команды/параметры, повторные одиночные параметры, отсутствующие значения, противоречивые опции, некорректные значения и непрочитанные завершающие аргументы. При ошибке не возвращать пригодную команду.
- Ни одна из этих функций не выполняет файловый или сетевой ввод-вывод, не запрашивает данные, не журналирует и не обращается к устройствам.

## 3. Режимы CLI

```text
app [--lang CODE] [--format text|json] --ui=no
app [--lang CODE] [--format text|json] --ui=no --once COMMAND [COMMAND OPTIONS]
```

- `--ui=no` без `--once` запускает интерактивный CLI REPL. Процессные параметры удаляются до разбора команд REPL.
- При запуске REPL в аргументах процесса допускаются только глобальные параметры; позиционные аргументы команды отклоняются с рекомендацией добавить `--once`, а не молча исполняются или игнорируются.
- `--once` требует ровно одну команду после себя и допустим только при `--ui=no`. Команда разбирается и исполняется один раз, затем процесс завершается.
- `--lang CODE` и `--format text|json` применяются ко всему запуску. Формат по умолчанию — `text`; `--format` не указывается отдельно для каждой команды REPL.
- Ввод/приглашение REPL и диагностические сообщения направляются в stderr. В режиме JSON каждая завершённая команда, включая командную ошибку, выдаёт ровно один JSON-объект в stdout.
- `help`, `version` и `quit` доступны в обоих режимах. В REPL `quit` отменяет принадлежащую процессу работу и завершает его с успехом. В one-shot это допустимая успешная команда без дополнительных действий.
- EOF штатно завершает REPL после отмены принадлежащей ему работы. Ctrl+C отменяет активную команду REPL и возвращает приглашение; прерывание one-shot-команды завершает процесс с кодом 130.

## 4. Поддерживаемые формы команд

```text
discover --interface INDEX --timeout DURATION [--repeat COUNT]
activate --device MAC [--device MAC ...] --password-stdin [--email EMAIL] [--yes]
network --device MAC [--device MAC ...] --password-stdin (--dhcp | --address IPv4/PREFIX --gateway IPv4) [--yes]
language list
language CODE
help
version
quit
--export-locale-template PATH
```

- `discover` требует индекс подходящего интерфейса и явный положительный конечный `--timeout` для каждого окна приёма. `--repeat` — целое число от `1` до `100`, по умолчанию `1`. Каждый цикл немедленно отправляет один probe и непрерывно принимает данные в течение всего timeout; следующий цикл начинается сразу по окончании предыдущего окна. Получение устройства не завершает цикл. Общее время ограничено приблизительно произведением `timeout × repeat` плюс настройка и очистка.
- `activate` и `network` принимают один или несколько повторяющихся параметров `--device MAC`. MAC должен быть корректным шестибайтовым EUI-48; дубликаты после нормализации отклоняются. При двух и более MAC обязателен `--yes`. Для одной цели one-shot не выводит дополнительное подтверждение.
- `--password-stdin` задаёт stdin как источник пароля. В REPL читать пароль при выключенном отображении символов; в one-shot читать одну строку, в том числе из перенаправленного stdin. Пока эти операции заблокированы protocol gate, пароль не читать; после включения операции получать секрет только после проверки команды, целей и подтверждения. Не принимать пароль как обычное значение опции, аргумент команды, переменную окружения, элемент отображаемой истории или диагностическое сообщение.
- Настройка сети требует ровно один из параметров `--dhcp` и `--address`. Для статического `--address` обязателен `--gateway`; с `--dhcp` шлюз запрещён. CIDR задаёт адрес и префикс.
- `language list` возвращает идентификаторы локалей M5. `language CODE` запрашивает точное переключение локали на время текущего процесса и не сохраняет выбор; в one-shot оно действует только во время данного запуска.
- `help` возвращает документированный каталог команд. `version` возвращает версию приложения/идентификатор сборки. `quit` принимается в обоих режимах согласно описанным правилам.
- `--export-locale-template PATH` — отдельная форма команды, несовместимая со всеми другими командами; вызывает M5 `ExportLocaleTemplate`.
- `activate` и `network` остаются в каталоге, но до реализации сквозных рабочих процессов, интерпретации результата устройства и контракта отмены завершаются ошибкой `unsupported` до чтения секретов и сетевого ввода-вывода. Это ограничение реализации, а не утверждение, что подтверждённые SADP XML активации или расчёт «запрос-ответ challenge-response» остаются непроверенными.
- Пользовательская сводка команд и описание аргументов находятся в [справке](../../../../HELP.md); поддерживать её синхронной с этой грамматикой и P4.3.

## 5. Токенизация REPL

- Разделять незаключённые в кавычки токены по пробелам ASCII/Unicode.
- Двойные кавычки группируют пробелы в один токен. Внутри двойных кавычек обратная косая черта экранирует только двойную кавычку или другую обратную косую черту. Вне двойных кавычек обратная косая черта — обычный символ.
- Отклонять незакрытые кавычки и недопустимые последовательности экранирования с ошибкой, не выводящей полную строку ввода.
- Не реализовывать shell expansion, подстановку переменных/команд, globbing, конвейеры, перенаправление или запуск shell.

## 6. Ошибки и тесты

Возвращать явные ошибки разбора, не выводя пароль или весь чувствительный ввод. Проверять токенизацию REPL и эквивалентность токенов one-shot; разделение режимов/глобальных параметров; количество команд one-shot; все формы команд; обязательный timeout, repeat по умолчанию и допустимые границы; повторные/дублирующиеся цели; порог `--yes`; взаимоисключающие параметры сети; локаль/help/version/quit/export; неизвестные и лишние аргументы; кавычки, экранирование кавычек/слешей, незакрытые кавычки и неподдерживаемый shell-синтаксис; отсутствие побочных эффектов разбора.
