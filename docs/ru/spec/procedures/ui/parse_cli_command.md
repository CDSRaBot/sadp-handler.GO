# Спецификация процедуры: P4.4 — ParseCLICommand
## Модуль: M4 — Интерфейс командной строки

Разобрать одну команду, введённую в интерактивном CLI REPL или переданную аргументами в режиме `--ui=no --once`, и вернуть типизированный вариант общего каталога P4.5. Подробные нормативные грамматика, модель и проверки определены в [англоязычной спецификации](../../../spec/procedures/ui/parse_cli_command.md).

- `--ui=no` без `--once` запускает интерактивный REPL; `--once` требует ровно одну команду и завершает процесс после её обработки.
- Общие параметры `--lang` и `--format text|json` применяются ко всему процессу; `--repeat` для `discover` по умолчанию равен 1 и ограничен диапазоном 1–100, `--timeout` обязателен и задаётся на каждый цикл.
- Команды `activate`/`network` принимают повторяемый `--device`; при нескольких целях обязателен `--yes`. До снятия protocol gate не читать пароль и не выполнять сетевые действия.
- REPL-токенизация поддерживает двойные кавычки и ограниченное экранирование, но не shell expansion/исполнение. Парсер не выполняет команды и не делает ввод-вывод.
