# Спецификация процедуры: P4.2 — SearchDevices
## Модуль: M4 — Интерфейс командной строки

## 1. Назначение

Фильтровать снимок обнаруженных устройств по пользовательскому запросу для отображения в списке устройств CLI. Эта процедура отвечает только за представление и не выполняет сетевой поиск, выбор устройств или операции над ними.

## 2. Контракт Go

```go
func SearchDevices(devices []parser.Device, query string) []parser.Device
```

- Выполнять поиск без учёта регистра по MAC-адресу, IPv4-адресу, серийному номеру и модели каждого устройства.
- Удалять пробельные символы в начале и конце запроса.
- Возвращать новый срез, не изменяя входной срез и его элементы.
- Если нормализованный запрос пуст, возвращать все устройства.
- Если совпадений нет, возвращать пустой срез; при nil-входе также возвращать пустой результат.
- Поддерживать фильтрацию полного списка устройств, в том числе когда результат используется для фокусировки на одном устройстве или множественного выбора. Состояние выбора и операции управляются отдельно и не должны выводиться из этого среза результатов.

## 3. Требования к обработке

1. Нормализовать запрос с помощью `strings.TrimSpace` и `strings.ToLower`.
2. Преобразовать значения для поиска в отображаемую форму и искать подстроку без учёта регистра.
3. Выполнять стабильную сортировку результатов: неактивные устройства (`Activated == false`) должны идти перед активными; порядок внутри каждой группы сохраняется.
4. Не изменять и не переупорядочивать исходный снимок обнаруженных устройств.
5. Применять фильтр только при отображении, не теряя исходный снимок обнаружения; при очистке запроса восстанавливать полный текущий снимок.

## 4. Ошибки и тесты

Эта процедура фильтрации данных в памяти не должна приводить к операционным ошибкам. Проверять пустые запросы и запросы из пробелов, поиск без учёта регистра по каждому полю, отсутствие совпадений, nil- и пустой ввод, фильтрацию и очистку запроса для списка устройств, стабильный порядок «неактивные прежде активных» и сохранение исходного среза.
