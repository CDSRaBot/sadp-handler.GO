# Спецификация процедуры: P0.2 — OpenMulticast
## Модуль: M0 — Адаптер платформы

## 1. Назначение

Открыть UDP-соединение для SADP multicast-трафика через один явно выбранный интерфейс хоста.

## 2. Контракт Go

```go
func OpenMulticast(iface Interface, group netip.AddrPort) (net.PacketConn, error)
```

- Отклонять неподходящий или недоступный интерфейс, неверную или не-multicast IPv4-группу, а также неверный или нулевой UDP-порт.
- Возвращать соединение, настроенное для указанного интерфейса и группы, либо ошибку без пригодного соединения.
- Возвращённое соединение поддерживает одновременно одного читателя и одного сериализованного писателя на том же интерфейсе, как требуется для запланированных M6 probe во время непрерывного приёма.
- Соединением владеет вызывающий код и обязан закрыть каждое успешно полученное соединение, если только владение не передано в M1 `Listen`; в этом случае `Listen` закрывает его при любом исходе.

## 3. Требования к обработке

1. До открытия сокетов проверить выбранный интерфейс и multicast endpoint. Не переключаться незаметно на другой интерфейс или endpoint.
2. Присоединиться к указанной IPv4 multicast-группе через выбранный интерфейс и настроить отправку и приём в соответствии с возможностями целевой ОС. Успешное обнаружение реальных устройств в реализации на Python делает её UDP-поведение с учётом выбранного интерфейса ориентиром совместимости; `239.255.255.250:37020` — текущая база endpoint, а не авторитетная константа протокола для всех устройств.
3. Где поддерживается, привязать сокет приёма к порту указанной группы (`37020` для наблюдаемого endpoint). Не копировать ветку Python для Windows, где выполняется привязка к эфемерному порту без присоединения к multicast-группе; поведение Windows нужно реализовать и проверить отдельно.
4. Обеспечить возможность одновременно выполнять один `ReadFrom` и сериализованный `WriteTo` на возвращённом соединении. Оба направления должны использовать выбранный интерфейс.
5. Не устанавливать неподтверждённый multicast TTL и не делать выводов о требованиях обнаружения между подсетями. Любая подобная настройка должна быть обоснована проверенным требованием.
6. При ошибке настройки закрыть частично инициализированный сокет и вернуть исходную причину в обёртке с контекстом операции и интерфейса. Не возвращать частично настроенное соединение как успешный результат.
7. Оставить отменяемое чтение и жизненный цикл цикла приёма модулю M1; возвращённым соединением владеет вызывающий код.

## 4. Ошибки и тесты

Возвращать явные обёрнутые ошибки для неверных аргументов, выбора интерфейса, отказа в разрешениях, ошибок привязки/присоединения к группе и неподдерживаемого поведения платформы. Проверять неверные endpoint-ы, привязку интерфейса/группы, очистку ресурсов при частичном сбое настройки, поведение поддерживаемых платформ и членство в multicast-группе на Windows. Тесты не должны зависеть от внешних устройств или действующей multicast-сети, если поведение сокетов можно внедрить через подмену.
