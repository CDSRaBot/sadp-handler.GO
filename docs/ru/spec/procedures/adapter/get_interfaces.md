# Спецификация процедуры: P0.1 — ListInterfaces
## Модуль: M0 — Адаптер платформы

## 1. Назначение

Перечислить сетевые интерфейсы хоста, которые могут использоваться для обнаружения SADP по IPv4.

## 2. Контракт Go

```go
func ListInterfaces() ([]Interface, error)
```

- При успехе вернуть ноль или более подходящих интерфейсов и nil-ошибку.
- Если перечисление интерфейсов или проверка адресов хоста завершается ошибкой, вернуть ошибку с контекстом операции. Не создавать фиктивные сведения об адаптерах.
- Пустой результат допустим, если ни один интерфейс не соответствует критериям.

`Interface` — типизированное значение, определённое в M0. Оно содержит индекс и имя интерфейса, аппаратный адрес, IPv4-префиксы и флаги.

## 3. Требования к обработке

1. Перечислять интерфейсы и адреса с помощью пакета Go `net`.
2. Включать только включённые интерфейсы, не являющиеся loopback и имеющие как минимум один пригодный IPv4-адрес.
3. Сохранять индекс и имя интерфейса, необходимые для привязки SADP-трафика к этому интерфейсу.
4. Копировать адреса и аппаратные адреса в возвращаемые значения; не предоставлять вызывающему коду изменяемые внутренние буферы.
5. Не полагаться на разрешение имени хоста для определения правильного интерфейса и не переключаться незаметно на другой интерфейс, если запрошенный недоступен.

Виртуальные интерфейсы не исключаются только потому, что они виртуальные; их пригодность определяется по тем же флагам и правилам адресации.

## 4. Ошибки и тесты

Возвращать обёрнутые ошибки при сбоях перечисления интерфейсов или получения адресов. Не использовать `panic` и не возвращать частично заполненные результаты так, будто перечисление прошло успешно.

Тесты должны охватывать loopback- и выключенные интерфейсы, отсутствие IPv4-адресов, несколько подходящих адресов, пустой результат и внедрённые ошибки перечисления, если реализация позволяет внедрять зависимости.
