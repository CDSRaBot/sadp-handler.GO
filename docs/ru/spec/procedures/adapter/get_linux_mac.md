# Спецификация процедуры: P0.3 — getLinuxMAC
## Модуль: M0 — Адаптер платформы

## 1. Назначение

Прочитать и проверить аппаратный адрес именованного сетевого интерфейса Linux или Android (Termux). Это внутренний платформозависимый помощник; для переносимого перечисления интерфейсов следует предпочитать API Go `net.Interface`.

## 2. Контракт Go

```go
func getLinuxMAC(interfaceName string) (net.HardwareAddr, error)
```

- Отклонять пустое имя интерфейса, `"."`, `".."`, а также имя с разделителями путей или нулевым байтом.
- При успехе возвращать проверенный шестибайтовый аппаратный адрес EUI-48.
- Если адрес интерфейса не удаётся прочитать или он некорректен, возвращать ошибку. Не возвращать пустую строку, заглушку или угаданный адрес.

## 3. Требования к обработке

1. Формировать путь sysfs с помощью `filepath.Join("/sys/class/net", interfaceName, "address")`.
2. Читать файл с помощью `os.ReadFile`.
3. Удалять пробельные символы по краям и разбирать значение через `net.ParseMAC`.
4. Отклонять разобранные адреса, длина которых не равна шести байтам.

Не использовать общий резервный адрес хоста, например значение, полученное через UUID: он может принадлежать другому адаптеру и не подходит на замену адресу запрошенного интерфейса.

## 4. Ошибки и тесты

Оборачивать ошибки чтения и разбора, указывая имя интерфейса и операцию, и сохраняя исходную ошибку. Не включать содержимое файла в сообщение об ошибке.

Тесты должны охватывать корректные и неверные адреса, отсутствующие и недоступные для чтения файлы, некорректные имена интерфейсов и отклонение адресов, не являющихся EUI-48.
