# Процедура: CheckFallbackEligibility

Fallback разрешён только при стратегии `sadp_first`, классифицированной
недоступности SADP, доступном существующем маршруте и подтверждённой
возможности ISAPI для текущей операции.

Ошибки входных данных, отклонение устройства, неверные учётные данные,
ошибка аутентификации, некорректный ответ, отмена, тайм-аут и ошибка
верификации дают конечный результат. Автоматическое изменение маршрутов и
подсетей не выполняется.
