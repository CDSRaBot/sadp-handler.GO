# Процедура: VerifyStatus

После активации или сетевой настройки выполняется ограниченный запрос
состояния через протокол завершившей операцию. Успех публикуется только при
подтверждении состояния и идентичности цели.

Ошибка проверки не запускает fallback. Отмена, тайм-аут, некорректные данные,
несоответствие цели и ошибка аутентификации возвращаются как типизированные
ошибки с сохранением причин. Пароли, challenge, HTTP-заголовки, XML и полные
payload не выдаются и не журналируются.
