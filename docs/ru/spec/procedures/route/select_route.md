# Процедура: SelectRoute

Процедура получает контекст, стратегию, операцию, цель и внедрённые
транспорты SADP/ISAPI, поставщик маршрута и поставщик возможностей.

Для `isapi_only` выполняются только проверки маршрута и возможностей ISAPI.
Для `sadp_first` сначала выполняется SADP; fallback возможен только для
классифицированной недоступности SADP. Отклонение устройства, ошибка
аутентификации, некорректный ответ, отмена, тайм-аут и ошибка верификации
останавливают операцию.

Результат содержит выбранный протокол, операцию, цель и безопасную
типизированную ошибку. Секреты и полные сетевые данные не возвращаются и не
записываются в журнал.

Для activation через ISAPI выполняется обязательная SDK-процедура
RSA-1024/65537, challenge и AES-128-ECB. Некорректные security-данные дают
конечную ошибку, а не capability fallback.
