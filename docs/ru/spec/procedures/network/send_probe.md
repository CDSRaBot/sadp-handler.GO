# Спецификация процедуры: P1.2 — SendInquiryProbe
## Модуль: M1 — Сетевое ядро

Отправить одну датаграмму SADP inquiry-probe на переданный адрес. Формат XML, валидация аргументов и точные правила ошибок определены в [нормативной процедуре на английском](../../../spec/procedures/network/send_probe.md).

Наблюдаемый запрос содержит корень `Probe`, UUID в поле `Uuid`, тип `inquiry` и `ResponseMode` со значением `2`. Процедура отправляет ровно один запрос, не ожидает ответа и не повторяет его. Соединение остаётся во владении вызывающего кода; содержимое пакета и UUID не журналируются.
