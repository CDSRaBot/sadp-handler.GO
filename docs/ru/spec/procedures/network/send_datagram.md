# Спецификация процедуры: P1.4 — SendSADPDatagram
## Модуль: M1 — Сетевое ядро

## 1. Назначение

Отправить одну сформированную вызывающей стороной SADP-датаграмму на целевой адрес через пакетное соединение, принадлежащее вызывающей стороне.

## 2. Контракт Go

```go
func SendSADPDatagram(
    ctx context.Context,
    conn net.PacketConn,
    target net.Addr,
    payload []byte,
    maxDatagramSize int,
) error
```

- Отклонять nil-контекст, соединение или целевой адрес, пустой payload, лимит вне `1..65507` либо payload, превышающий настроенный лимит.
- Не передавать владение соединением, не ожидать ответа и не повторять отправку.
- Отправлять ровно одну датаграмму, сохраняя переданные вызывающей стороной адрес и байты payload.

## 3. Требования к обработке

1. Проверять контекст непосредственно перед записью. Если задан deadline, ограничивать им запись, не меняя deadline чтения и не закрывая принадлежащее вызывающей стороне соединение.
2. Один раз вызвать `WriteTo`. Считать короткую запись ошибкой; не повторять её, чтобы не дублировать команду.
3. M3 использует API для SADP XML, например активации, сформированной P3.1. Выбранное соединение и целевой endpoint задаются M0/M6; XML `TargetMAC` определяет целевое устройство.
4. Не разбирать и не сопоставлять ответы. Их приём относится к M1 `Listen` и M2; семантика результата операции устройства относится к M3.
5. Не журналировать байты payload, учётные данные и поля безопасности устройства.

## 4. Ошибки и тесты

Возвращать `TransportError` со стабильным этапом `validation`, `write` или `short_write`, сохраняя исходную причину. Отмена должна распознаваться через `errors.Is`. Проверять nil-аргументы, неверные лимиты, пустой и слишком большой payload, заранее отменённый контекст, ровно одну запись, сохранение адреса/payload, короткие записи, ошибки записи и то, что соединение вызывающей стороны остаётся открытым.
