# Спецификация процедуры: P1.1 — Listen
## Модуль: M1 — Сетевое ядро

## 1. Назначение

Принимать UDP-датаграммы через пакетное соединение M0 и синхронно передавать каждую датаграмму указанному обработчику до отмены или сбоя.

## 2. Контракт Go

```go
func Listen(ctx context.Context, conn net.PacketConn, handle PacketHandler) error
```

- Возвращать ошибку при nil-контексте, соединении или обработчике.
- При вызове владение ненулевым соединением передаётся `Listen`. Закрывать его при любом исходе: неверные аргументы, отмена, ошибка транспорта или обработчика.
- Не терять ошибку закрытия соединения: включать её в возвращаемую ошибку, объединяя с основной ошибкой при необходимости. Возвращать nil при штатной отмене только при успешной очистке.
- При штатной отмене контекста возвращать nil. При неожиданной ошибке чтения или обработчика возвращать ошибку; не представлять сбой как успех.
- Обработчик не должен сохранять или изменять срез полученных байтов после возврата, если предварительно не скопировал его.

## 3. Требования к обработке

1. Читать в буфер размером `MaxSADPDatagramSize + 1`, чтобы обнаружить пакет сверх общего прикладного лимита M1/M2, а не передать его как незаметно усечённый корректный префикс.
2. Синхронно передавать данные через `handleDatagram`; не запускать неограниченную горутину на каждый пакет. Сохранять адрес отправителя.
3. Проверять отмену перед каждым чтением. Обеспечить однократное закрытие принадлежащего процедуре соединения при отмене, чтобы разблокировать ожидающее чтение. Ошибку чтения, вызванную отменой, считать штатным завершением; остальные ошибки чтения сохранять. Ошибку закрытия включать в результат, а не отбрасывать.
4. При неожиданной ошибке обработчика прекратить приём и вернуть обёрнутую ошибку. Обработчик уровня приложения отвечает за обработку ожидаемых ошибок проверки M2, если по политике некорректное объявление нужно отбросить.
5. Не разбирать XML и не формировать discovery-probe в этой процедуре.

## 4. Ошибки и тесты

Возвращать ошибки с контекстом этапа и исходной причиной; не включать байты пакета или секреты. Проверять nil-аргументы, закрытие соединения при любом исходе, обработку ошибки закрытия, штатную отмену во время заблокированного чтения, неожиданные ошибки чтения, последовательную передачу и сохранение отправителя, ошибки обработчика и пакеты на границе общего лимита датаграммы и сверх неё.
