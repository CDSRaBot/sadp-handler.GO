# Спецификация процедуры: P5.8 — SwitchLocale
## Модуль: M5 — Локализация

## 1. Назначение

Атомарно опубликовать полностью загруженные код локали и каталог как одно неизменяемое активное состояние.

## 2. Контракт Go

```go
type LocaleState struct {
    Code     string
    Messages map[string]string
}

func SwitchLocale(
    active *atomic.Pointer[LocaleState],
    candidate LocaleState,
) error
```

- Отклонять nil-указатель, недопустимый код, nil/пустой каталог и некорректные записи с ошибкой, не изменяя активное состояние.
- Возвращать nil только после защитного копирования полного кандидата и его атомарной публикации.
- Каталог-кандидат уже должен быть полным (обычно получен из P5.1); эта процедура не выполняет ввод-вывод или слияние fallback.

## 3. Требования к обработке

1. Проверить `candidate.Code` через P5.2 и проверить каждую пару ключ/значение.
2. Скопировать код и карту в новый `LocaleState`; не сохранять изменяемые ссылки на карту вызывающей стороны.
3. Выполнить одну атомарную запись указателя, чтобы читатели наблюдали либо предыдущее полное состояние, либо новое.
4. Опубликованное состояние и его карта неизменяемы. При одной операции отображения читатели должны загрузить указатель ровно один раз и не изменять указанную карту.
5. При ошибке точно сохранять предыдущее состояние. Переключение во время работы приложения не сохраняется в настройках.

## 4. Ошибки и тесты

Возвращать ошибки проверки без содержимого каталога; не использовать `panic`. Проверять nil-указатель, недопустимого кандидата, защитное копирование, конкурентных читателей, которые видят только целостные пары код/каталог, и неизменность прежнего состояния при ошибке.
