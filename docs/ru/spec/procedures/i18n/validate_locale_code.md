# Спецификация процедуры: P5.2 — ValidateLocaleCode
## Модуль: M5 — Локализация

## 1. Назначение

Проверить один идентификатор локали до его использования для формирования пути файловой системы или выбора каталога.

## 2. Контракт Go

```go
func ValidateLocaleCode(langCode string) error
```

- Принимать одну или более ASCII-букв, цифр, символов подчёркивания или дефисов.
- Отклонять пустые строки, пробелы, точки, разделители путей, NUL, не-ASCII-символы и любые прочие символы.
- Возвращать nil только для допустимого кода локали; при ошибке не возвращать нормализованное значение.
- Коды чувствительны к регистру и не канонизируются.

## 3. Ошибки и тесты

Ошибка указывает на недопустимый идентификатор локали и не должна выводить недоверенное значение, похожее на путь. Не использовать `panic`.

Проверять `en`, `en-US` и `pt_BR`; пустые строки и пробелы; точки/обход каталогов; прямой и обратный слеш; NUL; знаки пунктуации; не-ASCII-буквы.
