# Спецификация процедуры: P5.7 — ExportLocaleTemplate
## Модуль: M5 — Локализация

## 1. Назначение

Записать канонический встроенный английский каталог в новый файл для перевода.

## 2. Контракт Go

```go
func ExportLocaleTemplate(
    english map[string]string,
    destination string,
) error
```

- Отклонять некорректный английский каталог или пустое назначение с ошибкой.
- Возвращать nil только если полный шаблон JSON успешно записан и файл закрыт.
- Никогда не перезаписывать существующее назначение.

## 3. Требования к обработке

1. Проверить записи согласно правилам каталога P5.3.
2. Кодировать карту как один UTF-8 JSON-объект со стабильной сортировкой ключей и завершающим переводом строки.
3. Создавать файл эксклюзивно (`O_CREATE|O_EXCL`) с правами не шире `0644`; не усекать и не заменять существующие файлы.
4. Если после создания этим вызовом произошла ошибка записи или закрытия, удалить только созданный здесь частичный файл и включить ошибку очистки в возвращаемую ошибку.
5. Не менять активную локаль или настройки и не требовать внешние файлы локалей.

## 4. Ошибки и тесты

Сохранять ошибки файловой системы и включать путь назначения, но не содержимое каталога. Проверять точный успешный экспорт пар ключ/значение, детерминированную сортировку, пустой/некорректный ввод, отсутствующий родительский каталог, ошибки записи/закрытия, неизменность существующего файла побайтно и удаление частичного файла, созданного операцией.
