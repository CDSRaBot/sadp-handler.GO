# Спецификация процедуры: P5.3 — DecodeLocaleCatalog
## Модуль: M5 — Локализация

## 1. Назначение

Декодировать и проверить один ограниченный плоский JSON-каталог локали.

## 2. Контракт Go

```go
func DecodeLocaleCatalog(data []byte) (map[string]string, error)
```

- Отклонять пустой ввод и ввод размером больше 1 МиБ; при превышении размера возвращать `ErrCatalogTooLarge`.
- Возвращать ненулевую карту и nil-ошибку только для одного полностью корректного каталога.
- При ошибке возвращать nil и ошибку; не возвращать частичную карту.

## 3. Требования к обработке

1. Декодировать ровно один JSON-объект, отображающий строковые ключи в строковые значения. Отклонять массивы, скаляры, вложенные объекты/массивы, значения нестрокового типа, некорректный JSON и завершающие JSON-значения.
2. Отклонять повторяющиеся ключи, а не молча принимать последнее значение.
3. Требовать, чтобы каждый ключ и значение были непустыми и не состояли только из пробелов.
4. Не требовать наличия всех канонических ключей сообщений в переведённом каталоге: fallback выполняет P5.4.
5. Не журналировать содержимое каталогов или переданные пользователем строки перевода.

## 4. Ошибки и тесты

При превышении размера возвращать типизированный `ErrCatalogTooLarge`; сохранять причины JSON-парсера, не раскрывая содержимое каталога. Проверять граничные размеры, отклонение пустого объекта, повторяющиеся ключи, вложенные/нестроковые значения, некорректный JSON и завершающие значения, пробельные ключи/значения и отсутствие частичного результата при ошибке.
