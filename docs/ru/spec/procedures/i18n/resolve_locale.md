# Спецификация процедуры: P5.5 — ResolveLocale
## Модуль: M5 — Локализация

## 1. Назначение

Выбрать эффективную локаль при запуске из значения по умолчанию, необязательного значения настроек и необязательного переопределения CLI.

## 2. Контракт Go

```go
func ResolveLocale(
    settingsLocale string,
    cliLocale string,
    hasSettings bool,
    hasCLI bool,
) (string, error)
```

- Возвращать выбранный код локали либо ошибку; при ошибке возвращать пустой код.
- Локаль CLI имеет приоритет над настройками. Настройки имеют приоритет над значением по умолчанию `en`.
- Переданное, но пустое или недопустимое значение более высокого приоритета является ошибкой. Значение более низкого приоритета, переопределённое корректным значением более высокого приоритета, не проверяется и не может помешать выбору.

## 3. Требования к обработке

1. Выбрать `cliLocale`, если `hasCLI`; иначе `settingsLocale`, если `hasSettings`; иначе `en`.
2. Проверить только выбранный код вызовом P5.2 `ValidateLocaleCode`.
3. Не читать файлы, декодировать каталоги или менять активное состояние; не выполнять незаметный fallback, если эффективное запрошенное значение недопустимо или недоступно.

## 4. Ошибки и тесты

Ошибки указывают на этап разрешения локали запуска и не выводят недопустимые значения. Проверять значения по умолчанию, каждую пару приоритетов, отсутствующие и явно пустые значения, недопустимые эффективные значения и недопустимые значения низкого приоритета, переопределённые корректным значением высокого приоритета.
