# Спецификация процедуры: P5.4 — MergeLocaleCatalog
## Модуль: M5 — Локализация

## 1. Назначение

Создать защитный полный каталог сообщений, наложив корректный неполный перевод на канонический английский каталог.

## 2. Контракт Go

```go
func MergeLocaleCatalog(
    english map[string]string,
    translated map[string]string,
) (map[string]string, error)
```

- Отклонять nil- или пустой английский каталог, некорректные ключи/значения, nil-каталог перевода, некорректные записи перевода и ключи перевода, отсутствующие в английском каталоге.
- Возвращать новую ненулевую карту со всеми ключами английского каталога и переведёнными значениями, где они заданы.
- При ошибке возвращать nil и ошибку; не возвращать частично объединённый каталог.

## 3. Требования к обработке

1. Проверить все ключи и значения обеих карт на пустоту и строки, состоящие только из пробелов.
2. Отклонять ключи перевода, которых нет в каноническом английском каталоге, чтобы выявлять расхождение ключей/опечатки.
3. Скопировать все английские записи в новую карту и затем заменить переведённые значения.
4. Не изменять ни один вход. Возвращённая карта не должна ссылаться на входные карты; после публикации её считают неизменяемой.
5. Карта `translated` может быть пустой; в этом случае вернуть защитную копию английского каталога.

## 4. Ошибки и тесты

Ошибки указывают, какой каталог не прошёл проверку, не раскрывая его содержимое. Проверять частичный и полный перевод, английский fallback, неизвестные ключи, недопустимые/nil-карты, защитное копирование, отсутствие изменений входных данных.
