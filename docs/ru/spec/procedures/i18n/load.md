# Спецификация процедуры: P5.1 — LoadLocale
## Модуль: M5 — Локализация

## Назначение

Загрузить каталог запрошенной локали и вернуть независимую полную карту сообщений с английским fallback для отсутствующих переводов. Процедура не изменяет активное состояние локали.

## Контракт

Каноническая сигнатура Go и точные правила обработки `fs.FS` приведены в [нормативной процедуре на английском](../../../../spec/procedures/i18n/load.md).

- Отклонять nil-файловую систему, некорректный код локали и пустой/некорректный встроенный английский каталог.
- Для `en` возвращать защитную копию английского каталога без чтения внешнего файла.
- Для иной локали прочитать `locales/{langCode}.json`, декодировать и объединить с английским каталогом.
- При любой ошибке возвращать nil и ошибку; недоступная запрошенная локаль не означает успешный fallback на английский.
- Возвращённая карта не должна разделять изменяемую память с входными картами. Переключение состояния выполняет P5.8.

## Этапы и тесты

Вызвать P5.2 для проверки кода, P5.3 для проверки/декодирования каталога и P5.4 для слияния и копирования. Ошибки должны указывать этап и локаль без данных каталога и сохранять исходные причины.

Проверять встроенный английский без внешнего файла, полные и неполные переводы, отсутствующий файл, неверный код, некорректный JSON, защитное копирование и отсутствие частичного кандидата после сбоя.
