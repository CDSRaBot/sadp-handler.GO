# Спецификация процедуры: P5.1 — LoadLocale
## Модуль: M4 — Поддержка CLI (локализация)

## 1. Назначение

Загрузить плоский JSON-каталог переводов для CLI из предоставленной файловой системы. Если запрошенную локаль загрузить не удаётся, явно использовать английский запасной вариант.

## 2. Контракт Go

```go
type FallbackError struct {
    Language string
    Err      error
}

func LoadLocale(
    filesystem fs.FS,
    langCode string,
    english map[string]string,
) (map[string]string, error)
```

- При успехе вернуть проверенные сообщения запрошенной локали и nil-ошибку.
- Если каталог запрошенной локали не удаётся определить, прочитать, декодировать или проверить, вернуть копию проверенного английского каталога и `FallbackError`, оборачивающий исходную причину. Так вызывающий код явно узнаёт о переходе на запасной вариант.
- Если сам английский каталог не прошёл проверку, вернуть ошибку и не возвращать пригодный для использования каталог.
- Возвращаемые карты не должны ссылаться на карту `english`, переданную вызывающим кодом, или на внутреннее изменяемое состояние.
- `FallbackError` должен поддерживать проверку исходной ошибки через `Unwrap`.

## 3. Требования к обработке

1. Проверить `langCode`: это идентификатор локали, содержащий только ASCII-буквы, цифры, подчёркивания или дефисы. Отклонять разделители каталогов, обход путей и пустое значение.
2. Читать `locales/{langCode}.json` через `fs.FS`, используя разделители путей `/`.
3. Декодировать ровно один JSON-объект в `map[string]string`. Отклонять вложенные значения, значения нестрокового типа, некорректный JSON и данные после JSON-объекта.
4. Проверять резервный каталог: ключи должны быть непустыми, значения — строками.
5. При сбое чтения запрошенного каталога возвращать защитную копию английского каталога вместе с явным `FallbackError`; не утверждать, что запрошенная локаль загружена успешно.
6. Если в запрошенном переводе отсутствует ключ, CLI отображает сам ключ, как определено для потребителя локализации.

## 4. Ошибки и тесты

Не записывать содержимое каталогов в журнал. Оборачивать ошибки файловой системы и декодирования, сохраняя исходную причину.

Тесты должны охватывать корректные каталоги, неподдерживаемые коды локали, отсутствующие файлы, некорректный JSON и данные после него, вложенные значения и значения нестрокового типа, копирование резервного каталога, неверный резервный каталог, а также поведение `errors.As`/`errors.Unwrap` для `FallbackError`.
