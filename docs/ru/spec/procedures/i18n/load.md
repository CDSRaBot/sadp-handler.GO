# Спецификация процедуры: P5.1 — LoadLocale
## Модуль: M4 — Поддержка CLI (локализация)

## 1. Назначение

Загрузить и проверить один каталог локали и создать полный неизменяемый каталог сообщений с английским fallback для отсутствующих ключей перевода. Ошибка загрузки не должна заменять текущую активную локаль.

## 2. Контракт Go

```go
func LoadLocale(
    filesystem fs.FS,
    langCode string,
    english map[string]string,
) (map[string]string, error)
```

- `locales/en.json` — канонический исходный английский каталог: он задаёт полный стабильный набор ключей сообщений и их английские тексты. Встраивать его в бинарный файл с помощью `embed`, чтобы английский оставался доступен при отсутствии или пустой внешней папки локализаций.
- Все пользовательские сообщения приложения должны разрешаться по ключам канонического английского каталога. Не извлекать набор ключей из отображаемого текста или скомпилированного UI.
- `english` — встроенный проверенный английский каталог, доступный всегда, даже если внешняя папка локализаций отсутствует или пуста.
- Для `langCode == "en"` вернуть защитную копию `english`; наличие внешнего `locales/en.json` не требуется.
- Для другого языка вернуть каталог запрошенной локали, дополненный английскими строками, и nil-ошибку только при наличии и корректности её файла.
- Если папка локализаций пуста, запрошенный каталог отсутствует либо не удаётся прочитать, декодировать или проверить файл, вернуть `nil` и ошибку. Не возвращать английский каталог вместе с ошибкой как внешне успешный fallback.
- Вызывающий код меняет активный каталог только после получения полного каталога и nil-ошибки. При сбое он сообщает ошибку и сохраняет активную локаль.
- Возвращаемая карта не должна ссылаться на `english`, карту декодера файловой системы или изменяемое внутреннее состояние. После активации вызывающий код считает каталог неизменяемым.

## 3. Канонический каталог и экспорт шаблона

- Хранить исходный английский JSON в `locales/en.json` и встраивать его в бинарный файл. Этот файл — редактируемый источник и полный шаблон ключей для переводчиков; не поддерживать параллельную вручную заданную карту английских сообщений.
- Предоставить неинтерактивную CLI-операцию, например `--export-locale-template <path>`. Так как по умолчанию включён TUI, эту и другие разовые CLI-операции запускать с `--ui=no` (например, `app --ui=no --export-locale-template <path>`). Операция записывает копию встроенного английского каталога JSON со всеми исходными ключами и значениями.
- Экспорт должен работать без внешней папки локализаций и не менять активную локаль или обычные настройки. Он выполняется в стандартном CLI и не открывает и не переключает TUI.
- Не перезаписывать существующий файл назначения. Возвращать явную ошибку с указанием пути, если файл уже существует либо его нельзя создать/записать; существующий файл оставить без изменений.
- Экспортированный файл — исходный шаблон, а не требование, чтобы каждый перевод содержал все ключи. Частичные каталоги допустимы; отсутствующие переводы отображаются по-английски.
- После изменения английского каталога тестами проверять, что все используемые кодом ключи в нём существуют; экспорт должен содержать все канонические ключи без потерь и добавлений.

## 4. Выбор локали и приоритеты

Итоговая локаль определяется в следующем порядке; каждый следующий источник имеет приоритет над предыдущим:

1. Начальное значение — встроенный английский (`en`).
2. Если задан язык в файле настроек, использовать его.
3. Если задан язык в параметрах запуска, он переопределяет значение настроек.
4. Во время работы явный успешный выбор локали встроенной командой переопределяет текущую локаль до завершения процесса.

При запуске сначала определить приоритет настроек и параметров запуска, затем загрузить только итоговую локаль. Некорректное или недоступное значение с низшим приоритетом, переопределённое более приоритетным значением, не мешает запуску. Если итоговую запрошенную локаль загрузить нельзя, вывести ошибку и сохранить текущую локаль (при запуске — английскую); не переходить молча к менее приоритетному запросу. Переключение во время работы действует только в памяти процесса и не перезаписывает настройки, пока отдельное сохранение явно не специфицировано.

Приложение перечисляет локали для формирования списка runtime-переключения. Встроенный английский всегда доступен как базовая локаль. Если внешняя папка локализаций пуста или её нельзя перечислить, вывести ошибку и не открывать/предлагать переключение; при запуске оставить английский, во время работы — последнюю успешно выбранную локаль. Если при сканировании не найдено ни одного корректного неанглийского каталога, это ошибка, а не успешно сформированный пустой список.

## 5. Формат каталога и fallback

1. Проверить `langCode`: разрешены только ASCII-буквы, цифры, подчёркивание и дефис. Запрещены пустое значение, разделители путей и обход каталогов.
2. Читать `locales/{langCode}.json` через `fs.FS` с разделителями `/`. Английский (`en`) предоставляется встроенным каталогом и не требует внешнего файла.
3. Декодировать ровно один плоский JSON-объект в `map[string]string`. Отклонять вложенные и нестроковые значения, некорректный JSON и данные после объекта.
4. Проверить английский каталог и все предоставленные элементы локали: ключи и значения не должны быть пустыми или состоять только из пробелов. Отсутствующий ключ допустим; некорректная явно заданная запись делает каталог ошибочным.
5. Построить итоговый каталог из защитной копии английского и наложить на неё строки выбранного языка. Если для ключа сообщения нет перевода в выбранной локали (пара `en`/выбранный язык неполна), это сообщение отображается по-английски.
6. Если ключ отсутствует в обоих каталогах, резолвер отображает сам ключ и формирует диагностическое сообщение для журналов разработки/поддержки. Пустая строка не должна выводиться.
7. Не записывать содержимое каталога и пользовательские переводы в журнал.

## 6. Атомарное переключение во время работы

1. Хранить активный код локали и разрешённый каталог как единое состояние приложения.
2. При переключении загрузить и проверить полный кандидатный каталог, не меняя активное состояние.
3. При ошибке сообщить о ней на текущей локали и оставить без изменений как код активной локали, так и её каталог.
4. При успехе атомарно заменить состояние активной локали; последующие сообщения используют новый каталог. Подтверждение переключения выводится на новой локали.
5. Выбор точный: недоступная локаль является ошибкой, а не запросом молча перейти на английский или другой язык.
6. Рекомендуемые единые имена: ключ настроек `language`, параметр запуска `--lang`, встроенная команда выбора `language`. Во всех источниках использовать один нормализованный код локали.

## 7. Ошибки и тесты

Возвращать ошибки с указанием операции и кода запрошенной локали, не раскрывая содержимое каталогов. Сохранять исходные причины ошибок файловой системы и JSON-декодирования для проверки. Не возвращать ошибку fallback-типа вместе с пригодным каталогом, который вызывающий код может случайно установить как запрошенную локаль.

Тесты должны охватывать:

- Встроенный английский без внешней папки локализаций или `en.json`.
- Экспорт шаблона копирует все канонические ключи и значения, работает без внешних локалей, не меняет активную локаль/настройки и отказывается перезаписывать существующий файл.
- Ключи сообщений приложения проверяются по каноническому английскому каталогу.
- Запуск экспорта и других одноразовых CLI-операций с `--ui=no`, включая работу при перенаправленных потоках.
- Приоритет выбора из настроек, параметров запуска и runtime-команды.
- Корректные полные и частичные каталоги; отсутствующие ключи берутся из английского.
- Неизвестные ключи сообщений не дают пустой вывод.
- Пустую папку локализаций, отсутствующий и нечитаемый файл, некорректный JSON и данные после объекта, вложенные/нестроковые значения и некорректные записи.
- Неудачный запрос локали сохраняет активный код и каталог без изменений.
- Успешное runtime-переключение меняет код и каталог совместно.
- Защитное копирование и наблюдение конкурентными читателями только старого или нового полного каталога, но не частично объединённого состояния.
