# Спецификация процедуры: P5.1 — LoadLocale
## Модуль: M5 — Локализация

## 1. Назначение

Загрузить каталог запрошенной локали и вернуть независимую полную карту сообщений, дополнив отсутствующие переводы английскими. Процедура не изменяет активное состояние локали.

## 2. Контракт Go

```go
func LoadLocale(
    filesystem fs.FS,
    langCode string,
    english map[string]string,
) (map[string]string, error)
```

- Отклонять nil-файловую систему и пустой либо некорректный английский каталог с ошибкой и без пригодного результата.
- При `langCode == "en"` возвращать защитную копию проверенного `english`, не читая внешний файл.
- Для другого кода возвращать выбранный каталог, объединённый с английским, только если файл существует, доступен для чтения и прошёл все проверки.
- При любой ошибке возвращать nil и ошибку; не возвращать английский каталог как успешный результат, если запрошенная локаль недоступна.
- Возвращённая карта не должна ссылаться на `english` или изменяемое состояние декодера. После публикации вызывающая сторона считает её неизменяемой.

## 3. Требования к обработке

1. Вызвать P5.2 `ValidateLocaleCode`.
2. Проверить переданный канонический английский каталог по тем же правилам записей, что и P5.3.
3. Если код равен `en`, вызвать P5.4 с английским каталогом и как базовым, и как переводом, чтобы получить его защитную копию.
4. Иначе прочитать не более 1 MiB плюс одного байта из `locales/{langCode}.json`, используя разделители `/` в путях `fs.FS`. Если дополнительный байт присутствует, вернуть `ErrCatalogTooLarge`; не передавать в P5.3 усечённый префикс. Другие ошибки файловой системы оборачивать и возвращать.
5. Вызвать P5.3 `DecodeLocaleCatalog`, затем P5.4 `MergeLocaleCatalog`.
6. Возвращать полного кандидата только после успешного завершения всех этапов. Изменение активной локали оставлено P5.8 `SwitchLocale`.

## 4. Ошибки и тесты

При превышении размера возвращать типизированный `ErrCatalogTooLarge`, другие причины сохранять при оборачивании. Ошибки должны указывать этап проверки, чтения, декодирования или слияния и запрошенную локаль, не раскрывая содержимое каталога. Не использовать `panic`.

Проверять загрузку встроенного английского без внешнего файла, корректные полные и частичные переводы, файлы на границе 1 MiB и выше, отсутствующие/недоступные файлы, недопустимые идентификаторы локали, некорректные каталоги, защитное копирование и то, что при ошибках не возвращается частичный каталог и не меняется активное состояние.
