# Спецификация процедуры: P5.6 — ListLocales
## Модуль: M5 — Локализация

## 1. Назначение

Перечислить идентификаторы локалей, доступных для выбора во время работы приложения.

## 2. Контракт Go

```go
func ListLocales(filesystem fs.FS) ([]string, error)
```

- Отклонять nil-файловую систему с ошибкой.
- Возвращать отсортированный список, содержащий встроенную `en` и каждый внешний файл `locales/{code}.json`, код которого проходит P5.2.
- Если каталог отсутствует или не содержит внешних локалей, возвращать `["en"]` и sentinel `ErrNoExternalLocales`; вызывающие стороны считают это ожидаемым состоянием и продолжают работу со встроенным английским. Если существующий каталог невозможно прочитать, возвращать nil и обёрнутую ошибку файловой системы.
- При перечислении проверять только имена; содержимое каталогов проверяется в P5.1 при выборе локали.

## 3. Требования к обработке

1. Читать каталог `locales` с помощью `fs.ReadDir`.
2. Игнорировать директории и файлы не JSON. У JSON-файлов, кроме `en.json`, удалять суффикс `.json` и проверять код локали; недопустимые имена файлов локалей приводят к ошибке, а не предлагаются пользователю.
3. Включать `en` ровно один раз как встроенную локаль. Никогда не открывать и не проверять внешний `en.json`: встроенный каталог является каноническим и затеняет внешний.
4. Сортировать результат лексикографически и возвращать защитную копию среза.

## 4. Ошибки и тесты

`ErrNoExternalLocales` — sentinel для `errors.Is`; сопутствующий список `["en"]` пригоден к использованию. Сохранять прочие причины файловой системы, не журналируя содержимое каталогов. Проверять nil-FS, отсутствующие/недоступные/пустые каталоги, посторонние файлы, вложенные директории, недопустимые имена JSON-файлов, игнорирование внешнего `en.json`, встроенный английский, порядок сортировки и выявление некорректного содержимого при загрузке.
