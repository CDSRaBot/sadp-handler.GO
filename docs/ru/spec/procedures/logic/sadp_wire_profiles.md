# SADP wire profiles и optional workflows

Код разделяет операции SADP по wire-профилям. Существующий профиль
`legacy-sha256` сохраняет совместимость с текущим `SecurityResponse`.
Профиль `salted-aes` доступен только через явно переданный проверенный
кодировщик чувствительного поля.

Кодировщик не угадывает длину AES-ключа, KDF, IV, роль `Salt` или формат
`bSalt`. Пока нет воспроизводимого SADP test vector, отсутствие кодировщика
завершает операцию ошибкой и не отправляет payload.

Контрольные вопросы являются отдельной opt-in операцией. Пустой список не
превращается в запрос; три пары вопрос–ответ поддерживаются как типичный
вариант, но не зашиты как универсальное требование. Hik-Connect также
формируется отдельной операцией и не смешивается с активацией или настройкой
сети.

Транспорт может использовать operation-aware matcher: неподходящие или
относящиеся к другой операции датаграммы отбрасываются до истечения
единого deadline. Старые транспорты с методом `Exchange` остаются
совместимыми.
