# Спецификация процедуры: P3.0 — ValidatePassword
## Модуль: M3 — Логика устройств

Проверить пароль до построения команды управления устройством. Канонические правила Unicode, граничные случаи и тестовые ожидания находятся в [нормативной процедуре на английском](../../../spec/procedures/logic/validate_password.md).

Это формализованная политика приложения для детерминированной проверки, а не утверждение об универсальных требованиях Hikvision. Некорректный пароль возвращает явную ошибку; значение пароля не включается в текст ошибки или журнал.
