# Спецификация процедуры: P3.0 — ValidatePassword
## Модуль: M3 — Логика устройств

## 1. Назначение

Проверить пароль активации по политике совместимости с локальным референсом на Python, не журналируя и не сохраняя его.

## 2. Контракт Go

```go
func ValidatePassword(password string) error
```

- Возвращать nil только если пароль соответствует приведённой ниже политике.
- Для некорректного пароля возвращать ошибку валидации; не возвращать нормализованное или подменённое значение.
- Пустой ввод недопустим. Эта чистая функция валидации не выполняет ввод-вывод и не нуждается в контексте.

## 3. Политика совместимости

Референс на Python требует от 8 до 16 символов и наличие символов как минимум из двух из четырёх классов: строчные буквы, прописные буквы, цифры и не буквенно-цифровые символы. Для детерминированного контракта Go считать кодовые точки Unicode (runes), классифицировать буквы с `unicode.IsLower`/`unicode.IsUpper`, цифры — с `unicode.IsDigit`, а специальными считать runes, не являющиеся Unicode-буквой или Unicode-цифрой. Каждая rune учитывается не более чем в одном классе. Отклонять управляющие символы Unicode; пробелы и прочие runes, не являющиеся буквами/цифрами, считать специальными символами.

Это политика совместимости, выведенная из локального референса, а не гарантия протокола для всех устройств. Прежде чем утверждать универсальную совместимость активации, следует сверить её с политикой поддерживаемых устройств.

## 4. Ошибки, безопасность и тесты

- Сообщения об ошибках указывают на несоответствие политике пароля, но никогда не содержат переданный пароль.
- Не журналировать, не сохранять и не возвращать пароль из этой функции.
- Не использовать `panic`.
- Проверять длину 0, 7, 8, 16 и 17 кодовых точек; каждый класс по отдельности; все шесть пар классов; Unicode-буквы/цифры; комбинируемые знаки; пробелы; отклонение управляющих символов; использовать только синтетические значения.
