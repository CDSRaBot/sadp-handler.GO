# Спецификация процедуры: P3.5 — CalculateHash
## Модуль: M3 — Логика устройств

## 1. Назначение

Вычислить значение ответа на вызов, требуемое протоколом целевого устройства. Алгоритм и представление байтов определяются протоколом и не являются взаимозаменяемыми вариантами защиты.

## 2. Контракт Go

```go
func CalculateHash(password, challenge string) (string, error)
```

- Возвращать ошибку, если пароль или вызов пусты.
- Возвращать дайджест в шестнадцатеричном нижнем регистре и nil-ошибку только при успешном вычислении по алгоритму, определённому протоколом.
- Не записывать пароль, вызов или дайджест в журнал и не включать их в сообщения об ошибках.

## 3. Контракт алгоритма и условие проверки

Текущий вариант процедуры SADP предлагает вычислять SHA-256 от UTF-8-байтов строки `password + challenge` именно в таком порядке, а затем кодировать результат шестнадцатеричными символами нижнего регистра с помощью `crypto/sha256` и `encoding/hex` из Go.

Этот вариант не считается подтверждённым только потому, что он записан в документе. До заявления о совместимости реализации с устройствами необходимо сверить его с авторитетной документацией Hikvision или проверенными тестовыми векторами. Если подтверждённый протокол задаёт другой порядок, кодировку, нормализацию или алгоритм, эту процедуру и зависящую от неё процедуру формирования XML необходимо обновить вместе. При отсутствии вызова или невозможности проверки нельзя незаметно переходить на передачу пароля открытым текстом.

## 4. Ошибки и тесты

Для пустых входных значений возвращать явные ошибки проверки. Тесты должны использовать эталонные векторы из проверенного источника, проверять регистр и длину результата, а также некорректные входные данные. Не использовать реальные учётные данные в тестах.
