# Спецификация процедуры: P7.1 — LoadSettings

## 1. Контракт

```go
func Load(path string) (Settings, error)
```

Загрузить `settings.json`, проверить обязательные метаданные комментариев и
все значения настроек, применить defaults и вернуть одну типизированную
конфигурацию.

## 2. Обработка

1. При пустом `path` использовать `settings.json` в текущем каталоге.
2. При отсутствии файла вернуть `Defaults()` без ошибки.
3. Декодировать один JSON-документ через `encoding/json` и отклонить хвостовые
   данные.
4. Требовать `_comments` и ровно один комментарий для каждого листового ключа
   из M7; неизвестные ключи настроек или комментариев отклонять.
5. Проверить типы и границы из M7. Нулевые/отсутствующие значения разрешать
   только там, где это явно указано в M7.
6. Возвращать типизированную ошибку с исходной причиной файловой системы,
   декодирования или валидации. Частичная конфигурация не возвращается.

## 3. Проверка

Проверить отсутствие файла, полный шаблон, все нижние и верхние границы,
поведение нулевых значений, некорректный и хвостовой JSON, отсутствующие или
лишние комментарии, неизвестные настройки, недопустимые относительные пути и
несовместимые политики discovery.
