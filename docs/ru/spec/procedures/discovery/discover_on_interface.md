# Спецификация процедуры: P6.1 — DiscoverOnInterface
## Модуль: M6 — Координатор обнаружения

## Назначение и контракт

Выполнить один отменяемый сеанс обнаружения на выбранном интерфейсе: открыть multicast-соединение M0, отправить один inquiry-probe M1, принимать пакеты и разбирать объявления M2. Сигнатура и типы Go определены в [нормативной процедуре на английском](../../../../spec/procedures/discovery/discover_on_interface.md).

Отклонять nil-контекст, nil-обработчик и неподходящий интерфейс до сетевого ввода-вывода. Ошибки этапа и причины сохранять в возвращаемой ошибке. nil допустим только при штатной отмене и успешном закрытии всех ресурсов.

## Последовательность

1. Открыть одно соединение для `239.255.255.250:37020`.
2. Отправить ровно один probe. При ошибке отправки закрыть соединение и объединить ошибку очистки с исходной.
3. При успешной отправке передать владение соединением `Listen`; не использовать и не закрывать его отдельно после передачи.
4. При ошибке разбора передать обработчику событие `DatagramRejected` с отправителем и безопасной ошибкой; продолжить при успешном callback.
5. Для корректного объявления отправить `DeviceFound`. Ошибка callback завершает сеанс.
6. Не выполнять повторов, дедупликации, корреляции UUID и не считать `Hello` ответом на probe.

Тестировать порядок вызовов, очистку, отмену, продолжение после отклонённой датаграммы, оба наблюдаемых типа объявления и ошибки callback без реальной multicast-сети.
