# Спецификация процедуры: P6.1 — DiscoverOnInterface
## Модуль: M6 — Координатор обнаружения

Выполнить один отменяемый сеанс обнаружения на одном выбранном интерфейсе с непрерывной или ограниченной политикой отправки inquiry-probe. Нормативная сигнатура с `DiscoveryOptions`, условия режимов, порядок операций и требования к очистке описаны в [англоязычной P6.1](../../../../spec/procedures/discovery/discover_on_interface.md).

- Непрерывный режим отправляет первый probe сразу, затем каждые 60 секунд при непрерывном приёме до отмены.
- Ограниченный режим отправляет probe сразу, принимает объявления полный `--timeout` каждого цикла, затем запускает следующий цикл; `--repeat` задаёт число циклов в диапазоне 1–100. Отдельно взятый ответ не завершает цикл.
- M6 передаёт событие на каждый пакет; M4 строит видимый снимок, объединяя повторные объявления по нормализованной паре MAC + sender. Это не задаёт UUID-корреляцию.
- При штатной отмене или завершении ограниченного поиска сначала останавливать и дожидаться планировщика, затем отменять читателя; `Listen` закрывает соединение. Если ошибка чтения/обработчика возникла первой, сохранять также возможную ошибку выполнявшейся записи. Подробные требования и тесты — в нормативном документе.
