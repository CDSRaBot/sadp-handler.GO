# Спецификация процедуры: P2.2 — NormalizeMAC
## Модуль: M2 — Парсер данных

## 1. Назначение

Разбирать MAC-адрес устройства в проверенный канонический аппаратный адрес Go длиной шесть байтов для единообразного сравнения и сериализации протокола.

## 2. Контракт Go

```go
func NormalizeMAC(value string) (net.HardwareAddr, error)
```

- Принимать только представления MAC, поддерживаемые `net.ParseMAC`, и только если они задают шестибайтовый адрес EUI-48.
- При успехе возвращать разобранный `net.HardwareAddr` и nil.
- Для пустого, некорректного значения или значения, не являющегося EUI-48, возвращать ошибку. Никогда не возвращать исходную строку как успешный запасной результат.
- `net.HardwareAddr.String()` предоставляет каноническое отображение в нижнем регистре с разделителями-двоеточиями.

## 3. Требования к обработке

1. Разбирать значение через `net.ParseMAC`; не удалять произвольные не-шестнадцатеричные символы, так как это может превратить неверный ввод в другой адрес.
2. Требовать ровно шесть байтов.
3. Не записывать некорректный ввод в журнал без изменений, если он может содержать недоверенные управляющие символы.

## 4. Ошибки и тесты

Возвращать ошибку, которую вызывающий код может дополнить контекстом XML-поля или устройства. Вызывающий код решает, следует ли отбросить некорректное объявление или сообщить об ошибке.

Тесты должны охватывать стандартную форму с двоеточиями, другие формы, явно принимаемые `net.ParseMAC`, недопустимые символы, неверное число байтов, пустую строку и каноническое форматирование.
