# Спецификация модуля: M5 — Локализация

## 1. Назначение

Проверять, загружать, объединять и атомарно переключать каталоги локалей независимо от CLI и отображения терминала.

## 2. Ответственность

- Использовать встроенный `locales/en.json` как канонический набор ключей и английский резервный каталог.
- Проверять коды локалей и плоские JSON-каталоги, загружать запрошенный каталог и дополнять отсутствующие переводы английскими.
- Разрешать приоритет локали при запуске, перечислять внешние локали и экспортировать шаблон английского каталога.
- Публиковать новый код и каталог только после успешной полной загрузки кандидата.

Модуль не разбирает параметры CLI, не отображает текст интерфейса и не изменяет каталог после публикации. Отсутствующая или некорректная запрошенная локаль — ошибка, а не успешный переход на английский.

## 3. Контракт API Go

Канонические сигнатуры и детальные требования приведены в [англоязычной спецификации M5](../../../spec/modules/localization.md). API включает `ValidateLocaleCode`, `DecodeLocaleCatalog`, `MergeLocaleCatalog`, `LoadLocale`, `ResolveLocale`, `ListLocales`, `ExportLocaleTemplate` и `SwitchLocale`.

- `LoadLocale` возвращает независимую полную карту и не меняет активное состояние.
- `SwitchLocale` публикует неизменяемое полное состояние атомарно; при ошибке загрузки или переключения активная локаль не меняется.
- Ошибки выбора, перечисления и экспорта явные; содержимое каталога не включается в журналы.
