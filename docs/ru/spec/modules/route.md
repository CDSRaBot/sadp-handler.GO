# Спецификация модуля: M9 — выбор протокола

M9 выбирает SADP или ISAPI для каждой цели и операции. Стратегия
`sadp_first` используется по умолчанию, `isapi_only` выбирается явно.
SADP-активация отключена; для неё переход к ISAPI разрешён после подтверждения
маршрута и возможности устройства. Для остальных операций fallback разрешён
только после классифицированной недоступности SADP, подтверждения маршрута и
проверки возможности требуемой операции.

Обнаружение ISAPI работает только по известному адресу. После
аутентифицированного чтения `deviceInfo` возвращаются MAC, модель, серийный
номер и версия прошивки, если они присутствуют; переданный MAC должен
совпадать с ответом. Read-only discovery подключено к one-shot CLI.
Проверка маршрута ISAPI использует ограниченное по времени TCP-соединение,
а не endpoint возможностей. Явная привязка к интерфейсу пока не реализована
и отклоняется.

Отклонение устройства, ошибка аутентификации, некорректный или
несоответствующий ответ, отмена, истечение срока и ошибка проверки состояния
являются конечными результатами и не запускают fallback. Модуль не изменяет
адреса интерфейсов, таблицу маршрутизации, firewall или сетевые пространства.

Контракт и типизированные результаты соответствуют
[английской спецификации M9](../../../spec/modules/route.md). Транспорт
владеет сокетами и HTTP-ответами; M9 владеет только выбором и результатом.
ISAPI activation дополнительно требует доверенный проверенный профиль и
идентичность цели, EUI-48 MAC и предварительное состояние inactive. Готового
production-профиля пока нет, поэтому активация в приложении отключена.
Неаутентифицированное состояние само по себе не подтверждает личность.
`ActivationAttempted` сохраняется при ошибках после попытки PUT и не означает,
что устройство получило или применило запрос.

Реализован наблюдавшийся вариант RSA-1024/65537 challenge и AES-128-ECB;
универсальная совместимость не заявляется. Первичная активация не повторяет
запрос с новым паролем при требовании аутентификации. Непроверенные варианты
не используются.
