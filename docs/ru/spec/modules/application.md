# Спецификация модуля: M8 — Компоновка приложения

## 1. Назначение

Преобразовывать проверенные настройки M7 в одну типизированную
`RuntimeConfig` и собирать зависимости для M4, M5 и M6. JSON-схема настроек не
должна распространяться в протокольные или presentation-пакеты.

## 2. Контракт

M8 один раз применяет приоритет `defaults → settings.json → CLI → аргументы
команды`, преобразует duration-строки в `time.Duration`, создаёт `fs.FS` для
каталога локалей, `adapter.MulticastOptions` для M0, `DiscoveryOptions` для M6
и уровень `slog`.

M8 запрещает package-level provider и изменяемое глобальное состояние. M4 и M6
получают настройки через типизированные зависимости; M0, M1, M2, M3, M5 и M6
не читают `settings.json` самостоятельно.

## 3. Кроссплатформенность

Один и тот же `MulticastOptions` передаётся на Windows, Linux/Termux и macOS.
Различия socket API изолируются platform-specific seams M0. Unit-тесты
используют внедряемые openers; дополнительно требуется интеграционная проверка
multicast и discovery на каждой доступной целевой ОС.
