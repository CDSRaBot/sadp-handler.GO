# Спецификация модуля: M0 — Адаптер платформы

## 1. Назначение

Предоставлять кроссплатформенную границу для обнаружения локальных сетевых интерфейсов и открытия UDP-соединения, используемого сетевым ядром SADP. Работающая реализация обнаружения на Python проверена на реальных устройствах; её UDP-поведение с учётом выбранного интерфейса является ориентиром совместимости для Go. Наблюдаемый endpoint `239.255.255.250:37020` входит в текущую базу совместимости, но не является универсальной гарантией протокола. Низкоуровневый Ethernet SADP не входит в контракт адаптера, если этого не потребуют данные с устройств.

## 2. Обязанности

- Перечислять сетевые интерфейсы и предоставлять атрибуты, необходимые для выбора интерфейса обнаружения.
- Открывать UDP-соединение с настройками выбранного интерфейса и параметрами SADP multicast в соответствии с работающим поведением реализации на Python. Endpoint `239.255.255.250:37020` является текущей целью совместимости, а не универсальной гарантией протокола.
- Изолировать платформозависимые параметры сокетов и явно сообщать о неподдерживаемых настройках.
- Возвращать ресурсы с чётко определёнными правилами владения; вызывающий код закрывает каждое успешно открытое соединение.

Адаптер не отправляет запросы, не разбирает объявления устройств и не реализует правила управления устройствами.

## 3. Контракт API Go

Следующие сигнатуры описывают контракт модуля; конкретные пути пакетов и экспортируемые имена будут окончательно определены при реализации:

```go
type Interface struct {
    Index        int
    Name         string
    HardwareAddr net.HardwareAddr
    IPv4Addrs    []netip.Prefix
    Flags        net.Flags
}

type MulticastOptions struct {
    Group netip.Addr
    Port  uint16
    TTL   uint8
}

type AdapterErrorKind string

const (
    AdapterInvalidInterface    AdapterErrorKind = "invalid_interface"
    AdapterPermissionDenied    AdapterErrorKind = "permission_denied"
    AdapterUnsupportedPlatform AdapterErrorKind = "unsupported_platform"
)

type AdapterError struct {
    Kind AdapterErrorKind
    Err  error
}

func (e *AdapterError) Error() string
func (e *AdapterError) Unwrap() error

func ListInterfaces() ([]Interface, error)
func OpenMulticast(iface Interface, options MulticastOptions) (net.PacketConn, error)
```

- `ListInterfaces` возвращает подходящие интерфейсы и ошибку, если перечисление завершилось неудачно. Пустой результат допустим, если подходящих интерфейсов нет.
- `OpenMulticast` проверяет аргументы и возвращает соединение, настроенное для отправки и приёма UDP-трафика SADP через указанный интерфейс. При ошибке соединение нельзя использовать.
- Вызывающий код владеет возвращённым `net.PacketConn`, пока не передаст владение M1 `Listen`; если соединение не передано в `Listen`, вызывающий код обязан закрыть его. `Listen` закрывает переданное соединение при любом исходе.
- Возвращаемые данные используют сетевые типы Go из `net` и `net/netip`; переносимое поведение не должно зависеть от названий интерфейсов или внутреннего устройства сокетов конкретной ОС.

## 4. Выбор интерфейса и переносимость

- Исключать loopback-интерфейсы, интерфейсы в состоянии «выключен» и интерфейсы без пригодного IPv4-адреса для запрошенной операции.
- Сохранять достаточно данных об идентичности интерфейса (индекс и имя), чтобы привязать к нему SADP-трафик; не считать, что разрешение имени хоста указывает на правильный интерфейс.
- Получать `MulticastOptions` от M8 и через `net` присоединяться к настроенной
  multicast-группе на выбранном интерфейсе; где поддерживается, сокет приёма
  привязывается к настроенному UDP-порту.
- Python-референс устанавливает multicast TTL 64. Сохранять это значение только при подтверждении наблюдаемым поведением; само по себе оно не доказывает требуемый TTL SADP или необходимость межсетевого обнаружения.
- Unix-подобная ветка Python привязывает сокет к порту группы и присоединяется к ней на выбранном интерфейсе. Windows-ветка привязывает эфемерный порт и не вступает в группу. Это расхождение не является целевым поведением: проверить Windows multicast отдельно и возвращать ошибку при неподтверждённой настройке.
- Использовать пакет Go `net` для перечисления интерфейсов и работы с пакетными соединениями. Добавлять платформозависимый код только при необходимости, обусловленной поведением сокетов ОС.
- Поддерживать Windows, Linux (включая Termux, если доступны Go и необходимые сетевые разрешения) и macOS при поддержке требуемого поведения multicast.
- Возвращать ошибки привилегий, привязки и неподдерживаемой платформы с контекстом операции. Не выполнять незаметный переход на другой интерфейс.

## 5. Политика ошибок и ресурсов

- Проверять интерфейс и multicast-группу до открытия сокета.
- Оборачивать системные ошибки контекстом, достаточным для определения операции и интерфейса, сохраняя исходную ошибку для дальнейшей проверки.
- Для сбоев, по типу которых ветвится вызывающий код, возвращать `AdapterError` со стабильными категориями `invalid_interface`, `permission_denied` или `unsupported_platform`; исходная причина сохраняется через `Unwrap`. Пустой успешный результат `ListInterfaces` не является ошибкой.
- Закрывать частично инициализированные сокеты при сбое настройки.
- Не использовать `panic` для обычных ошибок перечисления интерфейсов или сокетов.
